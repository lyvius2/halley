# 신혼 생활 시작 예산 계획 사용 안내

`예산` 화면은 같은 그룹이 주택, 대출, 투입 가능한 자산, 혼수 예산을 한 계획으로 계산하는 PoC입니다.
금액은 모두 원 단위이며, 대출·세금·견적은 확정값이 아닌 참고값입니다.

## 계획 만들기와 주택 입력

1. 헤더의 `예산`에서 `+ 새 계획`을 누릅니다.
2. 등록한 매물이 있으면 `등록 매물 선택`에서 고릅니다. 주택명·가격·전용면적이 계획으로 복사되며 이후 수정할 수 있습니다.
3. 수기 계획은 거래유형, 지역, 주택명, 가격, 전용면적, 계약금·잔금 자기자금을 직접 입력합니다.
4. `주택 예산 저장`으로 저장합니다.

## 부대비용 자동 추정

`부대비용 자동 추정`은 매매가·전용면적·대출금·거래유형을 기준으로 취득세, 중개보수,
법무사·등기, 이사, 입주청소의 참고값을 제안합니다.

- 먼저 추정값과 주의사항을 확인한 뒤 `입력칸에 적용`을 눌러야 입력값이 바뀝니다.
- 적용한 값은 `자동 추정`으로 표시됩니다.
- 특정 금액을 직접 수정하면 그 항목만 `수기 입력`으로 표시되고, 이 출처도 저장됩니다.
- 서울 외 지역의 중개보수는 서울 상한요율 참고값이므로 해당 지자체 조례를 확인해야 합니다.
- 주택 수·규제지역·부가세·실제 이사 조건은 PoC 입력에 포함하지 않으므로 계약 전 중개사·법무사·이사업체에 확인해야 합니다.

## 자산·대출·혼수

- 자산은 그룹 구성원별로 입력합니다. 평가금액과 실제 투입 가능 금액을 나누며, 제외를 선택하면 합계에서 뺍니다.
- 대출 조건은 대출금, 연이자율, 기간, 상환 방식을 저장합니다. 예상 월 원리금은 참고용 계산입니다.
- 혼수 품목은 시나리오별 선택, 보유품 제외, 품목 예산 수정이 가능합니다.
- 후보·대안 상품 URL은 허용된 쇼핑 도메인에서만 읽습니다. 읽기에 실패하면 상품명과 예상가를 직접 입력하면 됩니다.

## 시나리오와 요약

- `최소 시작`, `현실적인 추천`, `여유 있는 시작`은 혼수 선택을 일괄 변경합니다.
- 이후 품목을 직접 고치면 `사용자 정의` 시나리오로 전환됩니다.
- 요약 카드와 `계산 기준 보기`에서 초기 필요자금, 확보 자금, 부족/잔여 자금, 월 주거비의 근거를 확인할 수 있습니다.

## 초기 데이터 적용

- 로컬 H2 개발 환경은 `src/main/resources/data.sql`을 Spring SQL 초기화로 실행합니다. H2의 `MERGE` 문을 사용해 재실행해도 seed가 중복되지 않습니다.
- PostgreSQL 운영 DB를 수동으로 구성할 때는 `docs/DDL.sql`을 적용한 후 `docs/DML-budget-items.sql`을 적용합니다. 이 파일은 PostgreSQL의 `ON CONFLICT` 문법을 사용합니다.
